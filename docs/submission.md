# Submission draft

KnowledgePulse turns conflicting organisational instructions into reusable, attributed answers. Sentinel scans raw exports, shows the passages that disagree and routes a question to a relevant expert. In a staged car-display interface, the expert explains the missing context through ElevenLabs. The assistant reads back the clarification and requires explicit confirmation before the backend saves it. Colleagues can then find the exact answer, named expert, timestamp and original sources.

The prototype covers IKEA bicycle allowances and Volvo overtime. Rule extraction is repeatable; optional AI handles new wording within configured topics. Data, driving context and identities are simulated. Original documents remain available.
